# Navion COMSOL MATLAB Workflow

用于磁导航系统的磁场仿真、驱动矩阵构建与电流反算。

## 项目内容
- COMSOL 单位电流磁场导出
- MATLAB 驱动矩阵构建
- 工作空间可达性分析
- 磁场方向与目标场强反算

## 文件结构
- `magnetic_robot_control/`：主程序与控制模块
- `count_reachable_points.m`：工作空间可达点统计
- `RobotTeach.sln`：相关工程文件
